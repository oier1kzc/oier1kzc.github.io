# [F. Two Subtrees](https://codeforces.com/contest/1767/problem/F)

## Statement

给定一个 $n \ (1 \leq n \leq 2 \cdot 10 ^ 5)$ 个点的有根树，点 $1$ 是根。

给定一个长为 $n$ 的数组 $a _ 1, \cdots, a _ n$，点 $u$ 的权值是 $a _ u (1 \leq a _ u \leq 2 \cdot 10 ^ 5)$。

给定 $m \ (1 \leq m \leq 2 \cdot 10 ^ 5)$ 次询问，每次询问给出两个点 $x, y$，内容如下

- 考虑在 $x, y$ 子树内的所有点 $w$ 构成的可重集（如果同时在 $x$ 和 $y$ 的子树中则算两次）。将这些点的权值写下来，找到出现次数最多的数，如果有多个，则找最小的数，为这次询问的答案。

## Solution

设一个数据结构 $\mathcal D$ 可以支持

- $\mathcal O(f(n))$ 的时间内插入或删除一个元素。其中 $n$ 是插入元素的总个数。
- $\mathcal O(g(n))$ 的时间内计算所有插入元素的众数，若有多个则找到最小的。其中 $n$ 是插入元素的总个数。

允许离线。

### PreSolution1

考虑设计数据结构 $\mathcal D$，满足 $f(n) = \mathcal O(1)$，$g(n) = \mathcal O(\sqrt n)$。

具体来说，要维护一个可重集，支持 $\mathcal O(1)$ 插入一个数，$\mathcal O (\sqrt n)$ 查询最小众数。

其中 $n$ 为总共不同数个数。允许离线。

将所有插入的数拿出来，用 $(x, c)$ 描述数字 $x$ 出现了 $c$ 次，这样的数对一共有 $\mathcal O(n)$ 个。

将所有数拿出来，离线数一遍出现次数，找到这样 $\mathcal O(n)$ 个 $(x, c)$ 数对，以 $c$ 为第一关键字、$x$ 为第二关键字，按 $c$ 从大到小、$x$ 从小到大排序。

问题转为，维护一个长为 $n$ 的数组，$\mathcal O(1)$ 将某个位置赋为 $1$，$\mathcal O(\sqrt n)$ 查最靠前的数的位置。

取 $B = \sqrt n + \mathcal O(1)$，对每 $B$ 个位置分块处理即可。

空间复杂度为 $\mathcal O(n)$。

### PreSolution2

对于每个点，求出其子树众数。

对于树上的每个点 $u$，求出其所有儿子中，$\text{size}$ 最大的点，记为其重儿子。

设递归函数 dfs 输入为 $u$，计算 $u$ 子树的所有点的答案，并返回包含 $u$ 子树内所有元素的数据结构 $\mathcal D$。

对于每个点 $u$，先枚举所有轻儿子，递归计算子树答案，并且清空 $\mathcal D$。

再递归重儿子计算子树答案。不清空 $\mathcal D$。

扫一遍所有轻儿子，将 $u$ 和轻儿子子树内点的信息加入 $\mathcal D$ 中。

此时 $\mathcal D$ 中所有元素即为 $u$ 子树内所有元素。用 $\mathcal O(g(n))$ 查答案即可。

时间复杂度为 $\mathcal O(n f(n) \log n + n g(n))$。

若用 PreSolution1 中所给出的数据结构 $\mathcal D$ 维护，时间复杂度为 $\mathcal O (n \sqrt n)$。

### MainSolution

对树 dfs，对每个点 $u$，求出

- $fa[u]$，表示节点 $u$ 的父亲节点
- $sz[u]$，表示点 $u$ 的子树内节点数量。
- $bg[u]$，表示 $u$ 再 dfs 序中的位置，下标从 $1$ 开始。

分块，设定阈值 $B$。

对于每个点 $u$，称 $u$ 是轻的，当且仅当 $sz[u] < B$，否则称其是重的。（由于我不太擅长使用中文，在这里声明以下，下文中的所有“重点”意思均为一个重的点，而非表示强调）

将所有询问离线。

对于每个询问 $(x, y)$，$x$ 和 $y$ 的顺序是无所谓的，不妨设 $bg[x] < bg[y]$，以下默认该条件存在。

称一个询问 $(x, y)$ 是轻的，当且仅当 $x$ 是轻的，否则称其是重的。

将询问分成轻重两部分处理。

#### 轻询问

对树做一遍 PreSolution2，遍历到点 $y$ 时，处理所有 $(x, y)$ 的询问。

考虑到 $sz[x] < B$，暴力枚举 $x$ 子树内所有点，暴力加入 $\mathcal D$ 中，然后查询答案。

时间复杂度为 $\mathcal O(n f(n) \log n + q B f(n) + q g (n))$。

若用 PreSolution1 中所给出的数据结构 $\mathcal D$ 维护之，时间复杂度为 $\mathcal O(n \log n + q B + q \sqrt n)$。

#### 重询问

考虑将所有重点 $u$ 拿出来，构成点集 $S$。

若 $S$ 为空，即只有轻点，即只有轻询问。以下默认 $S$ 非空。

观察性质。$S$ 是一个连通块。因为若点 $u$ 满足 $sz[u] \geq B$，则 $sz[fa[u]] \geq B$。

于是 $S$ 可以看成一棵以 $1$ 为根的树。且这棵树的叶子数量不超过 $\left \lfloor \dfrac n B \right \rfloor$，因为每个叶子节点的子树不交，而又都 $\geq B$。

将 $S$ 剖成若干条链，满足对于每条链 $P = \{p _ 1, \cdots, p _ k\} \subset S$，有

- 对于所有 $1 \leq i < k$，$p _ i$ 是 $p _ {i + 1}$ 的父节点。
- 对于所有 $1 \leq i < j \leq k$，有 $sz[p _ i] - sz[p _ j] < B$。

把每个点都单独剖成一条链，是合法的。考虑让剖得的链都是极长的，具体地，考虑一个重点 $u$，先递归剖其所有（重点）儿子 $v$ 子树，若可以将 $u$ 剖到某个 $v$ 所在的链 $P$ 中（即满足 $sz[u] - sz[p _ k] \leq B$），则剖到 $P$ 中；否则将 $u$ 单独剖成一条链 $P = \{u\}$。

接下来说明，这样剖出的链的数量是 $\mathcal O \left( \dfrac n B \right)$ 级别的。考虑链会怎样结束。对于链顶 $u$，

- 若 $u = 1$，即是根节点，这样的链只有 $1$ 条；
- 否则，$fa[u]$ 存在。若 $fa[u]$ 的（重点）儿子不仅有 $u$，这可以看成在 $fa[u]$ 的位置，将多个链合并为了一条。考虑在所有这样的 $fa[u]$ 的位置算其对 $u$ （即链顶数，即链数）的贡献，对于所有 $S$ 中的点 $v$，其对 $u$ 的贡献有 $\mathcal O(\text{deg}(v))$ 次，其中 $\text{deg}(v)$ 表示 $v$ 的度数，因为 $S$ 的叶子数量不超过 $\left \lfloor \dfrac n B \right \rfloor$，所以 $\mathcal O \left(\sum \text{deg} (v) \right) = \mathcal O \left( \dfrac n B \right)$。于是这样的链有 $\mathcal O \left( \dfrac n B \right)$ 条。
- 否则，$fa[u]$ 的（重点）儿子仅有 $u$ 这一个。设包含 $u$ 的链 $P = \{p _ 1, \cdots, p _ k\}$，其中 $p _ i$ 是 $p _ {i + 1}$ 父节点（$p _ 1$ 即 $u$）。那么将 $u$ 和 $fa[u]$ 剖成两条链，说明 $sz[fa[u]] - sz[u] \geq B$。考虑将所有在 $fa[u]$ 子树中且不在 $p _ k$ 子树中的点标记，因为 $sz[fa[u]] - sz[u] \geq B$，这样标记的点至少有 $B$ 个。并且可以发现，每个点最多被一条链标记。于是这样的链有 $\mathcal O \left( \dfrac n B \right)$ 条。

于是这样剖出来的链的数量是 $\mathcal O \left( \dfrac n B \right)$ 级别的。

对于所有询问 $(x, y)$，根据 $x$ 在哪条链上，将 $(x, y)$ 分成 $\mathcal O \left( \dfrac n B \right)$ 类。对于每类询问，分别处理。

对于每条链，设链顶为 $u$，先将 $u$ 上所有点加入 $\mathcal D$ 中，对整棵树做一遍 PreSolution2。对于分类在该链上的询问 $(x, y)$，遍历到点 $y$ 时，将 $u$ 子树中除了 $x$ 子树外的部分删去，查一次答案，再将删去的点加回去。

根据划分出来的链的性质，对于每个询问，额外进行删除和加入点一共是 $\mathcal O(B)$ 个。于是这部分总时间复杂度为 $\mathcal O \left(\dfrac n B \cdot n \log n \cdot f(n) + q B f(n) + q g(n) \right)$。

若用 PreSolution1 中所给出的数据结构 $\mathcal D$ 维护之，时间复杂度为 $\mathcal O \left( \dfrac {n ^ 2 \log n} B + q B + q \sqrt n \right)$。

于是处理轻重询问，可以在 $\mathcal O \left( \dfrac {n ^ 2 \log n} B + q B + q \sqrt n \right)$ 的时间复杂度内完成。

取 $B = \mathcal O \left( \sqrt {\dfrac {n ^ 2 \log n} q} \right)$ 以平衡之，则上述时间复杂度为 $\mathcal O \left( n \sqrt {q \log n} + q \sqrt n \right)$，$n, q$ 同阶时为 $\mathcal O \left( n \sqrt {n \log n} \right)$。至此可以解决本题。

## Code

实现时可以写成莫队的形式。具体来说，对于 PreSolution2 的部分，先做树链剖分，确定 dfs 序，所有点 $u$ 按照 $bg[u]$ 从小到大排序，然后在 dfs 序上跑莫队。它的过程恰 PreSolution2 的逆过程（如果按照 $bg[u]$ 从大到小排序，这两个过程就完全一致），于是时间复杂度也一致。

```cpp
#include <stdio.h>
#include <string.h>

#include <vector>
#include <algorithm>

#define LOG(FMT...) fprintf(stderr, FMT)

#define eb emplace_back

using namespace std;

const int N = 200005;
const int B = 1600;

int n, m, a[N];
vector<int> e[N];
int fa[N], son[N], sz[N];
int bg[N], ed[N], lab[N], ids;
int bot[N], id[N], idz;
struct Query {
  int x, y, k;
  bool operator < (const Query &t) const {
    if (id[x] != id[t.x]) {
      return id[x] < id[t.x];
    }
    return bg[y] < bg[t.y];
  }
} qrs[N];
int res[N];
struct DS {
  const int BS = 600;
  struct Pair {
    int x, y;
    bool operator < (const Pair &t) const {
      return x != t.x ? x > t.x : y < t.y;
    }
  } q[2 * N];
  int cur[2 * N], pre[4 * N], nxt[4 * N], buc[N];
  int tag[2 * N / B + 5];
  bool ws[2 * N];
  void prework() {
    for (int i = 1; i <= n; ++i) {
      q[2 * i - 1] = (Pair){++buc[a[i]], a[i]};
      q[2 * i] = (Pair){++buc[a[i]], a[i]};
    }
    sort(q + 1, q + 2 * n + 1);
    memset(buc, 0, sizeof buc);
    for (int i = 1; i <= 2 * n; ++i) {
      int &j = buc[q[i].y];
      pre[i] = j, nxt[j] = i, j = i;
    }
    int k = 2 * n;
    for (int i = 1; i <= 2 * n; ++i) {
      if (!nxt[i]) {
        nxt[i] = ++k, pre[k] = i;
        cur[q[i].y] = k;
      }
    }
  }
  void exv(int x) {
    x = a[lab[x]];
    cur[x] = pre[cur[x]];
    ++tag[cur[x] / B];
    ws[cur[x]] = true;
  }
  void ers(int x) {
    x = a[lab[x]];
    ws[cur[x]] = false;
    --tag[cur[x] / B];
    cur[x] = nxt[cur[x]];
  }
  int qry() {
    for (int i = 0; ; ++i) {
      if (tag[i]) {
        for (int j = i * B; ; ++j) {
          if (ws[j]) {
            return q[j].y;
          }
        }
      }
    }
    return -1;
  }
} ars;

void dfs1(int x) {
  if (fa[x]) {
    e[x].erase(find(e[x].begin(), e[x].end(), fa[x]));
  }
  sz[x] = 1;
  for (int y : e[x]) {
    fa[y] = x, dfs1(y), sz[x] += sz[y];
    if (sz[y] > sz[son[x]]) {
      son[x] = y;
    }
  }
  if (son[x]) {
    swap(*e[x].begin(), *find(e[x].begin(), e[x].end(), son[x]));
  }
}

void dfs2(int x) {
  bg[x] = ++ids, lab[ids] = x;
  for (int y : e[x]) {
    dfs2(y);
  }
  ed[x] = ids;
  if (sz[x] >= B) {
    for (int y : e[x]) {
      if (sz[bot[y]] > sz[bot[x]]) {
        bot[x] = bot[y];
      }
    }
    if (!bot[x] || sz[x] - sz[bot[x]] >= B) {
      bot[x] = x;
      id[x] = ++idz;
    } else {
      id[x] = id[bot[x]];
    }
  }
}

int main() {
  scanf("%d", &n);
  for (int x = 1; x <= n; ++x) {
    scanf("%d", a + x);
  }
  for (int i = 1; i < n; ++i) {
    int x, y;
    scanf("%d%d", &x, &y);
    e[x].eb(y), e[y].eb(x);
  }
  scanf("%d", &m);
  for (int i = 0; i < m; ++i) {
    scanf("%d%d", &qrs[i].x, &qrs[i].y);
    if (bg[qrs[i].x] > bg[qrs[i].y]) {
      swap(qrs[i].x, qrs[i].y);
    }
    qrs[i].k = i;
  }
  dfs1(1), dfs2(1);
  for (int x = 1; x <= n; ++x) {
    if (sz[x] < B) {
      id[x] = idz + 1;
    }
  }
  ars.prework();
  sort(qrs, qrs + m);
  int times = 0;
  for (int i = 0, lx = 1, rx = 0, ly = 1, ry = 0; i < m; ++i) {
    const int &x = qrs[i].x, &y = qrs[i].y;
    if (sz[x] < B) {
      while (lx <= rx) {
        ars.ers(rx--);
      }
      lx = bg[x], rx = bg[x] - 1;
      while (rx < ed[x]) {
        ars.exv(++rx);
      }
    } else {
      while (rx < ed[x]) {
        ars.exv(++rx);
      }
      while (lx > bg[x]) {
        ars.exv(--lx);
      }
      while (rx > ed[x]) {
        ars.ers(rx--);
      }
      while (lx < bg[x]) {
        ars.ers(lx++);
      }
    }
    while (ry < ed[y]) {
      ars.exv(++ry);
    }
    while (ly > bg[y]) {
      ars.exv(--ly);
    }
    while (ry > ed[y]) {
      ars.ers(ry--);
    }
    while (ly < bg[y]) {
      ars.ers(ly++);
    }
    res[qrs[i].k] = ars.qry();
  }
  for (int i = 0; i < m; ++i) {
    printf("%d\n", res[i]);
  }
  return 0;
}
```
